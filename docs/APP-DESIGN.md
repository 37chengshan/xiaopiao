## 1. 设计语言：Apple 系统式（不是"拟物"，也不是"渐变"）

- **底色用系统灰白**：浅色分组底 `#F2F2F7`、卡片纯白；深色底 `#000000`、卡片 `#1C1C1E`。暖纸只出现在**小票纸本身**（`paper` 保持微暖白），App chrome 全部中性。
- **两套风格整机可切换**（我的 → 外观）：**Apple**（系统灰白 + Action Blue `#0066CC`，Inter/SF 式无衬线）与 **Claude**（奶油底 `#FAF9F5` + 珊瑚 `#CC785C` + 衬线标题）。切换只换 palette 与 type，不改布局；两套都必须能看。
- **只有一个交互强调色**：Apple = Action Blue，Claude = 珊瑚；朱砂红降级为**印章专用**。
- **语义色**：红 `#FF3B30`、绿 `#34C759`、橙 `#FF9500`、青 `#30B0C7`；只做浅底深字图标块。
- **层次来源**：底色差 + 留白 + 字重，不靠描边。阴影只给浮层（导航胶囊、sheet、浮动坞），两档就够。
- **圆角一套**：10 / 14 / 20 / 28 / 胶囊；同一层级同一值。
- **按钮（Apple 四层）**：Filled 胶囊（每屏 ≤1 个）· Tinted（accent 15%）· Gray（systemFill）· Plain 文字。**无描边、无渐变、无内高光、无投影**；手感靠按压 scale 0.96 + 变暗 100ms + 触感 + 弹簧回弹。
- **动效**：默认临界阻尼弹簧（response ≈0.35s）；浮层可拖动关闭、速度投影；尊重「减少动态效果」。

## 2. 信息架构与导航

```
首次打开 → 引导 4 屏（价值 / 自动记账授权 / 数据底线 / 个性化）→ 首页
用户版 5 位：AI 对话 ｜ 账本 ｜ [首页·记账+小票] ｜ 圈子 ｜ 我的（**已实现**）
小店版 5 位：概览 ｜ 洞察 ｜ [发起实验] ｜ 结果 ｜ 我的（含「回到用户版」）
```

- **中间主按钮永远代表"当前产品的主任务"**：用户版 = 记账首页（不切换页面，只是高亮 + 长按语音）；小店版 = 发起实验（进流程）。
- 根页**一律没有大标题**：顶栏 44–52dp，放日期/头像/搜索；只有子页面才有返回 + 小标题。大字号（34）只出现在引导页与小票纸。
- 「我的」= 分组列表：外观 / 语言 / 打印音效·震动 / 默认记账方式 / 通知自动记账 / 数据与隐私 / **切换到小店版** / 重看引导 / 关于。每项一行标题，最多一行灰字。

## 3. 首页 = 记账 + 小票（合并）

从上到下（全部零滚动可达关键动作）：

1. **紧凑顶栏**：日期 +「今天 3 笔 ¥46」一行摘要；右侧头像（进「我的」）。
2. **今日小票卡**：纸张缩略（半张渐隐）+「打印」主按钮；零消费日 =「今天钱包休息」+ 仍可打印空小票。
3. **常驻记录坞（dock）**：固定在导航上方，**不随内容滚动**。
   - 点输入框 → 手动表单 sheet（默认路径）；
   - 长按输入框/主按钮 → 语音 sheet（§4.2）；
   - 输入框右侧「＋」→ 手动 / 导入账单。
4. **今日明细**：分类图标块 + 备注 + 等宽金额；超过 6 笔折叠成「还有 N 笔」。
5. **最近几天小票**：横向小票缩略，点开即打印那一天。

3.5 **AI 对话（最左 tab）**
- 对话流：助手先开口（补漏记、昨日回顾、订阅到期、周报预告）；助手消息无气泡，用户消息浅色气泡；卡片（确认卡、周报卡、图表卡）全宽嵌流。
- 底部输入：文字 + 长按麦克风；离线或模型不可用时降级为模板回复并明说「现在只能做本机统计」。
- 对话只陈述用户自己的账本，不推荐、不比价、不给理财结论。

## 4. 记一笔

### 4.1 三条入口，一个确认卡
| 入口 | 默认？ | 行为 |
|---|---|---|
| 手动表单 | ✅ 默认 | 金额键盘 + 分类九宫格 + 备注/日期，2 次点击完成 |
| 一句话（文字） | 否 | 输入「午饭 32 骑车 2」→ L0 解析 → 一笔或多笔确认卡 |
| 语音 | 否（长按） | 系统 ASR 转写作文字，之后与一句话完全同路径 |

设置「默认记账方式」= 手动 / 一句话；**手动为默认**。

### 4.2 长按语音
- 长按 dock 主按钮 → sheet 弹起：波形条随音量起伏、实时转写文字、松手结束（可上滑取消）。
- 识别完成 → 文本进 L0 解析 → 确认卡（多笔时逐条可编辑/删除）→ 确认入账。
- 失败/静音：一行小字「没听清，再说一次」，可切回手打。

### 4.3 语音技术选型（不调 deepseek）
- **Android**：`SpeechRecognizer`，API 31+ 优先 `createOnDeviceSpeechRecognizer()`（端侧、免费、离线），不可用回落系统在线识别（厂商服务，仍免费）。不做自研 ASR、不上传音频到我们自己的服务。
- **Web**：`SpeechRecognition`（Chrome/Edge）可用则用，否则只留键盘麦克风；音频不出本机。
- **解析**：文本 → **本机 L0 规则**（金额/日期/分类/商户词典，中英语料 ≥100 句/语言单测）→ 只把 L0 解析不了的句子送 deepseek-flash。
- 成本控制：批量句子一次请求、输入 ≤200 字、每日调用上限、失败静默降级到「补一句备注」。

## 5. 圈子 = 家人共享（群聊形态）

- **一个圈子 = 一个「家」**（可建多个：家人/情侣/室友），成员 ≤6，每人有头像与共享名片。
- **可见度按项授权（默认最保守）**：
  | 项 | 默认 |
  |---|---|
  | 今日总额 | 开 |
  | 分类构成 | 开 |
  | 周报与头衔 | 开 |
  | 单笔明细 | **关** |
  | 小票全文 | **关** |
  未授权项在群里显示 `¥ ···`，不显示金额也不显示商户。
- **群聊流**：成员每天自动发一条「日小票卡」（按授权脱敏）+ 可点赞/表情/一句回复；系统消息（周报出炉、成就）也是气泡。
- **我的可见范围**：圈子页顶部成员头像行 → 点头像看/改 TA 能看到我什么；撤回后历史消息立即脱敏（本地模型即时生效）。
- **数据底线**：圈子数据只在成员之间，**绝不进 B 端聚合**；真实多人同步需要登录/邀请/推送（见 §11 待拍板）。
- 小游戏与人格测试放圈子内（按 SPEC §6），每个游戏一行「娱乐，不构成建议」。

## 6. 小店版 = 整机模式

- 全局状态 `AppMode { User, Merchant }`，持久化；**不是跳一个页面**，而是换整个外壳：导航、首页、配色（B 端用墨绿 `#2F6B57` 做 accent）、文案（「顾客」不说「用户」）。
- 进入：我的 →「切换到小店版」→ 1 屏说明（数据全是演示）→ 概览。
- 退出：小店版「我的」→「回到用户版」。
- B 端导航：概览（今日客流/客单/回头客）· 洞察（人群画像）· [发起实验] · 结果 · 我的。

## 7. AI：模型与边界

- **模型**：`deepseek-v4.1-flash`，只经 QMuse 云函数调用；key 只存平台 secret（`cloud set-secret`），App/Web 代码里永不出现。
- **调用点只有三处**：① 一句话/语音解析兜底 ② 对话回答 ③ 周报文案润色。其余（统计、分类、日历）全部本机。
- **降级链**：L0 规则 → flash → 模板文案。任何一层超时 2s 直接下探，不转圈。
- **费用**：按 token 计费，单句解析成本极低但**不是零**；需要 tt 提供 key 并充值，设每日上限（默认 200 次/人/天），超限静默降级。
- **规则包** `shared/ai-rules/`：persona / guardrails / categories / parse-corpus / templates / titles，中英各一套，改规则必跑语料测试。

## 8. 引导（首开 4 屏，可跳过，我的里可重看）

1. 价值：「每天一张会说话的 receipt」——衬线大字只在这次的纸面动画上；
2. 自动记账：解释通知读取，**不自动弹权限**，点「去开启」才跳系统设置；
3. 数据底线：原文只在本机 / 贡献默认关 / 可撤回，三个图标要点；
4. 个性化：外观三选一 + 默认记账方式 + 声音震动。

## 9. 演示数据制度（对应反馈 1）

- 任何含演示数字的屏幕/卡片：**屏内必须有 `DemoChip`**，且卡片标题写「演示」；分享图片右下角水印「演示数据」。
- 演示数据与真实数据**物理隔离**（不同 repository 实例、不同 id 段、绝不混排）。
- 交付前跑一次「演示数据审计」：逐屏截图核对，清单写进验收报告；缺标记即为 Bug。
- 单测：演示路径必须产出带标记的渲染参数（如 `ReceiptLayout` 的 DEMO 行、`DemoChip` 的可见性）。

## 10. 字体与数字（对应反馈 2，已落地）

> 已实施：`app/src/main/res/font/inter_{regular,medium,semibold}.ttf`（OFL），`XpFonts.sans` 承载拉丁与数字，中文走系统回退；金额一律 `tnum`。


| 用途 | 方案 |
|---|---|
| 拉丁/数字 | 打包 **Inter**（OFL），标题 600 / 正文 400 / 大数字 600 |
| 中文 | 不打包（体积），回退系统：vivo = 系统无衬线；Web = `PingFang SC` → `Noto Sans SC` |
| 金额 | 全部 **tabular-nums**（`FontFeatureSettings("tnum")`），右对齐，不截断 |
| 字号档（5 档） | 34（仅引导/纸面）· 22 标题 · 17 正文 · 15 次要 · 13 说明 |
| 行高 | 正文 1.45；大标题 1.15；金额行 1.0 |
| 字重 | 400 正文 / 500 列表标题 / 600 强调与金额；不用 <400 |

Web 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, "PingFang SC", "Noto Sans SC", sans-serif` + `font-variant-numeric: tabular-nums`。
