## 1. 设计语言：Apple 系统式（不是"拟物"，也不是"渐变"）

- **底色用系统灰白**：浅色分组底 `CanvasGrouped` `#F5F5F7`、卡片纯白 `Card`；深色底 `#000000`、卡片 `#1C1C1E`。暖纸只出现在**小票纸本身**（`Paper`），App chrome 全部中性。
- **两套风格整机可切换**（我的 → 外观）：**Apple**（系统灰白 + Action Blue `#0066CC` 作 accent）与 **Claude**（奶油底 `#FAF9F5` + 珊瑚 `#CC785C`）。切换只换 palette 与 type，不改布局；两套都必须能看。
- **accent 只做三件事**：文字链接、分段/选中的下划线、图标与数值的强调。**accent 不填充按钮、不做大面积底色。** 朱砂红降级为**印章专用**（`Stamp`）。
- **按钮只有两级**：
  | 级别 | 外观 | 用在哪 |
  |---|---|---|
  | 实心 | `Primary` 墨黑 `#1D1D1F` 底 + `OnPrimary` 白字，胶囊，高 48–52dp | 每屏 ≤1 个的主行动（保存、确认、开始打印） |
  | 系统灰填充 | `Fill` `#EDEDF0` 底 + `Ink` 字，胶囊，高 44–48dp | 次级动作（取消、跳过、筛选、重置前的备选） |
  文字链接（accent、无底色）与分段控件不算层级。**无描边、无渐变、无内高光、无投影**；手感靠按压 scale 0.96 + 变暗 100ms + 触感 + 弹簧回弹。
- **语义色**：`Negative` `#D70015`（红）、`Positive` `#248A3D`（绿）、`Warning` `#B25000`（橙）、`Info`（= accent）；只做浅底深字的图标块与差额文字，不做整块底色。
- **层次来源**：底色差 + 留白 + 字重。阴影只给浮层（导航胶囊、sheet、打印条），两档就够。
- **圆角一套**（`XpRadius`，Apple / Claude）：小 8 / 10、卡 11 / 14、大 18 / 20、浮层 28、导航胶囊 32、主键 圆形；**同一层级同一值**，不临时写 `RoundedCornerShape(17)`。
- **动效**：默认临界阻尼弹簧（response ≈0.35s）；浮层可拖动关闭、速度投影；tab 切换零位移（淡入 120ms）；尊重「减少动态效果」。

## 2. 信息架构与导航：4 tab + 中间动作，没有首页

```
首次打开 → 引导 3 屏（价值 / 两个手势+打印 / 数据底线）→ 落到「记账」
用户版：[记账] ｜〔记一笔〕｜ AI ｜ 圈子        （3 个 tab + 1 个动作；设置 = 右上角齿轮）
小店版：[概览] ｜ 洞察 ｜〔发起实验〕｜ 结果 ｜ 我的     （整机模式，见 §6）
```

| 位置 | 名称 | 内容 | 备注 |
|---|---|---|---|
| 1（最左，默认落地） | 记账 | 账单列表 + 统计报表（页内分段） | 唯一出现过「今天花了多少」的地方 |
| 中间（凸起圆键） | 记一笔 | **动作，不是页面**：点 = 手动表单，长按 = 语音 | 不切 tab、不改变当前页，关闭后回原处 |
| 3（中心键右边） | AI | 类 GPT 多轮对话：聊天记账 / 消费分析 / 家人圈子分析 | tt#17；AI 的所有输出只落在这里 |
| 4（最右） | 圈子 | 群聊流 + 排行榜 + 小游戏 | §5 |
| — 右上角 | 设置 | 齿轮进入独立页面（不是 tab），带返回 | tt#15；外观 / 音效震动 / 通知记账 / 数据与隐私 / 切换到小店版 / 重看引导 / 关于 |

> 顺序以 tt 原话为准：tt#9「最左侧是记账/统计…记一笔…ai…圈子」、tt#21 再次确认；AI 在中心键**右边**。

- **没有首页**：启动直接落「记账」。v3 的「首页 · 小票卡 / 紧凑顶栏日期摘要 / 最近几天小票横排」全部作废，小票改为按需打印（§3.1）。
- **根页一律没有大标题**：顶栏高 52dp，左标题（17/600，如「记账」「圈子」「我的」），右侧最多 2 个图标按钮（28dp 触达框 44dp）。
- **中间主键形态**：66dp 圆形，`CanvasGrouped` 描一圈 4dp 的「挖空」边再填 `Primary`，上浮 14dp 压在导航胶囊上；图标 `+` 白色。选中态不适用（它不是目的地），按下只做 scale 0.92 + 变暗。
- **导航胶囊**：半透明材质（`Card` 94% / 深色 `Surface2` 94%），高 64dp，圆角 32，左右各留 16dp；图标 24dp + 标签 10sp，选中 = accent 图标与文字，未选中 `InkSecondary`。
- **打印入口统一在顶栏**：「记账」与「统计」两页的右上角都是同一颗小票图标（`Icons.Outlined.ReceiptLong`，语义「打印今日小票」），全 App 仅此一处（§3.1）。
- 「我的」= 分组列表：每项一行标题，最多一行灰字，右侧箭头或开关；不放大卡片、不放插画。

## 3. 「记账」tab = 账单 + 统计（无首页）

一个 tab 装两件事，用顶栏右侧的两颗图标分开：

| 入口 | 图标 | 结果 |
|---|---|---|
| 账单（默认） | — | 日期分组卡片列表 + 顶部汇总条 + 搜索/筛选（§3.2） |
| 统计 | `Insights` | 收支报表页（§3.3） |
| 打印 | `ReceiptLong` | 直接进打印覆盖层，打完回原页（§3.1） |

- 账单页顶部**不再有纸卡**：只有一条汇总（今日支出大数字 + 本月支出/收入两列，高度 ≤88dp），下面直接进列表。
- **零消费日**：汇总条显示「今天钱包休息」+ 一句「仍可打印空小票」的次级文字，列表显示今天那一组空态行（虚线 + 「今天还没记账」+ 手打入口）。
- 列表首帧先画骨架（无转圈）；空账本 = 一屏插画位 + 一颗实心「记一笔」。

### 3.1 打印入口与小票覆盖层

- **入口**：顶栏右上小票图标，**点一下就打印**。v3 的「长按底部小票键 1.5 秒」**作废**；长按该图标不做事（避免误触）。
- **流程**（全屏覆盖层，不切 tab）：打印机口 → 纸条逐行滑出（每行轻触感，可关音效）→ 合计数字滚动 → AI 一句点评 → 头衔印章盖下 → 停在「已打印」，底部两颗按钮（实心「撕下分享」/ 灰填充「完成」）。
- **关闭**：左上 ×、系统返回、或「完成」；返回后**原页面与滚动位置不变**；撕下分享后回同一位置。
- **空小票**：零消费日照样能打，票面写「今天钱包休息」+ 头衔「钱包休眠者」。
- **提醒直达**：21:30 的推送（`OPEN_TODAY`）直接打开打印覆盖层，不经过列表。
- **无障碍**：图标 `contentDescription = "打印今日小票"`，TalkBack 单击即打印；打印覆盖层首次进入把焦点放在标题上，读屏播报「今日小票，合计 ¥x」。

### 3.2 账单页结构（照参考钱包 `041428 / 041500 / 041512 / 041515 / 041519`）

自上而下：

| 区块 | 规格 |
|---|---|
| 顶栏 | 左「记账」17/600；右：统计图标 + 小票图标 |
| 汇总条 | 卡（`Card`，圆角 14，内边距 16）：主行「今日支出」13/`InkSecondary` + 「¥18.28」22/600 tnum；次行「本月支出 ¥631.92　本月收入 ¥120.00」13/`InkSecondary`；右侧一条 7 根迷你柱（近 7 天，高 32dp，`Accent` 30%，今天 `Accent`）。**不做预算/结余建议**（产品原则：不给理财结论） |
| 搜索 + 筛选 | 一行：胶囊搜索框（`Fill` 底，高 40dp，左放大镜 18dp，占位「搜索商户、备注、金额」，点开独立搜索页）+ 右侧「筛选」文字按钮（有条件生效时写「筛选 2」） |
| 日期分组卡 | `GroupedSection`：白卡 `XpRadius.m`，卡间 12dp；卡头：左「10月28日 今日」「10月26日 星期一」（13/`InkSecondary`），右「支出 ¥18.28　收入 +¥0.00」（13/`InkSecondary`，两段等宽，零消费日写「零消费」）；卡内分隔线 `Hairline` 0.5dp、左缩进 **58dp**（`dividerInset = 58.dp`，对齐文字起点，不切图标） |
| 列表行 | 见下表；行高 64dp（带小字行 72dp），每屏 8–9 行，行内左右 padding 16dp |
| 列表底 | 留 104dp 避开导航胶囊 |

**行解剖（只有三件事 + 可选一行小字）**

| 元素 | 规格 |
|---|---|
| 分类图标块 | 40dp 方块，圆角 `size * 0.28` ≈ 11dp；默认 `Fill` 底 + `Ink` 线图标 22dp（`Category.icon()`，13 个分类各一枚）；语义例外：会员订阅用 `WarningSoft`/`Warning`。**emoji 只出现在小票纸与徽章上**，列表不用 |
| 名称 | **一个**：商户名（`Txn.merchant`），16/500，单行省略；**不再**用分类名当标题 |
| 金额 | 右对齐，`titleMedium` 600 tnum；支出 `Ink` 不带符号；收入前缀 `+`、`Positive` |
| 小字（可选，0 或 1 行） | 优先用户备注（`Txn.note`，13/`InkSecondary`，单行省略）；没有备注且来源是**自动**（`Source.NOTIFICATION` / `CSV`）时，写来源标签 chip（`Source.label`：通知自动 / 账单导入，11sp，`Fill` 底、胶囊）。手动与一句话不标来源。二者不并排，任何情况下都不出现分类名与时间 |

- 明确禁止：分类名副标题、时间副标题、分类名 + 时间两行灰字、图标外的色块描边。
- 时间只在分组卡头表达（日期），行内不重复；跨天的时间信息只在详情/编辑 sheet 出现。
- **左滑删除**：单行左滑 96dp 出现红色（`Negative`）「删除」，松手即删并弹撤销 toast 5s（「已删除「瑞幸」　撤销」）；不移动其他行。
- **长按进多选**（参考 `041519`）：顶栏变成「全选 / 已选 N 项 / 取消」，行首出复选框，底部浮起实心「删除」（一次删多笔，不提供撤销时二次确认）。
- 行点击 = 编辑 sheet（金额/分类/备注/日期），编辑后原地更新并高亮 300ms。

**筛选 sheet（底部浮层，`041515`）**

| 分组 | 控件 |
|---|---|
| 收支类型 | chip：支出 / 收入 |
| 时间 | chip：本月 / 上月 / 今年 / 自定义；自定义下出两个日期胶囊（起 — 止），点开日期选择器 |
| 分类 | 右侧入口「去选择分类 ›」，进二级 sheet 多选（13 个分类九宫格） |
| 金额 | 两个胶囊「最低金额 — 最高金额」，数字键盘，单位元、内部转 `Cents` |
| 账单来源 | chip：通知自动 / 一句话 / 手动 / 账单导入 |

- chip 规格：高 36dp 胶囊，未选 `Fill` 底 + `Ink` 字 15sp；选中 `AccentSoft` 底 + `Accent` 字 600（**不加描边**）；分组标签 13sp/`InkSecondary`，组间 20dp。
- 底栏固定：左「重置」、右「确认」，均为文字链接（accent 600），中间留空；安全区 padding。
- 确认后：列表回到顶部，筛选行内联显示已选条件（可单条 ×）、顶部计数「N 笔 · 共 ¥x」。
- 搜索页：同一套筛选入口；输入即搜（300ms 防抖），命中高亮；空结果 = 一行「没有匹配的账单」+ 「清空条件」链接。

- 空态：柱状图换成一条虚线基线 + 「这段时间还没有账单」；KPI 显示 `¥0`，环比格写「—」。

- 所有数字来自本机统计（`insights/`），AI 只写文案；无数据时全部显示 `¥0` 而不是假涨幅。

#### 3.4 AI 对话（第二格）

- 对话流：助手先开口（补漏记、昨日回顾、订阅到期、周报预告）；助手消息无气泡，用户消息浅色气泡；卡片（确认卡、周报卡、图表卡）全宽嵌流。
- 顶部一行能力标签（「本机统计 · 可问账本」），不放标题大图。
- 底部输入：文字 + 长按麦克风；麦克风与中间主键走同一套语音（§4.3），识别完不直接入账，先出确认卡。
- 离线或模型不可用时降级为模板回复并明说「现在只能做本机统计」。
- 对话只陈述用户自己的账本，不推荐、不比价、不给理财结论。

## 4. 记一笔

### 4.1 三条入口，一个确认卡

| 入口 | 默认？ | 行为 |
|---|---|---|
| 手动表单（点中间主键 / 长按后手打） | ✅ 默认 | 底部 sheet：金额大字 + 支出/收入切换 + 日期时间 + 分类 5 列九宫格 + 备注 + 数字键盘（含「再记一笔」），2 次点击完成 |
| 一句话（文字） | 否 | 输入「午饭 32 骑车 2」→ L0 解析 → 一笔或多笔确认卡 |
| 语音 | 否（长按主键） | 系统 ASR 转写作文字，之后与一句话完全同路径 |

设置「默认记账方式」= 手动 / 一句话；**手动为默认**。表单顶部切换「手动 / 一句话」两个分段，不在这里再开语音（语音只挂在主键与对话页麦克风上）。

### 4.2 中间主键手势（点 / 长按）

- **载体**：导航正中的 66dp 圆形主键（§2）。它不切换页面，所以手势结束一定回到原 tab、原滚动位置。
- **轻点** → 手动表单 sheet 上滑（圆角 20，遮罩 `Scrim`）。
- **长按（约 250ms 触发）** → sheet **改为语音态**：语音条从主键位置**向左展开**到屏宽减 32dp，主键留在最右当「结束/松手」把手；展开动画 220ms 弹簧。
- **声波**：随**实时音量**起伏（RMS → 0–1，带平滑，静音时是一条呼吸线），右侧同步显示已识别到的 partial 文本，让用户知道「它听到了什么」。
- **结束**：松手 → 停止识别 → 文本进本地 L0 解析 → 确认卡（金额 + 商户 + 分类，可改）；确认卡里给「再记一笔」。
- **取消**：按住时**向上滑**超过 60–80dp 即取消（波形收成一条线 + 触感 reject），松手不入账。
- 无权限 / 识别失败：语音条内一行小字 + 「手打」按钮，不弹窗、不挡操作。
- 无障碍：主键语义「记一笔」，长按动作在无障碍菜单里暴露为「说一句」。

### 4.3 语音技术选型（不调 deepseek）

- **Android**：`SpeechRecognizer`，API 31+ 优先 `createOnDeviceSpeechRecognizer()`（端侧、免费、离线），不可用回落系统在线识别（厂商服务，仍免费）。不做自研 ASR、不上传音频到我们自己的服务。
- **Web**：`SpeechRecognition`（Chrome/Edge）可用则用，否则只留键盘麦克风；音频不出本机。
- **解析**：文本 → **本机 L0 规则**（金额/日期/分类/商户词典，中英语料 ≥100 句/语言单测）→ 只把 L0 解析不了的句子送 deepseek-flash。
- 成本控制：批量句子一次请求、输入 ≤200 字、每日调用上限、失败静默降级到「补一句备注」。

## 5. 圈子 = 家人共享 + 排行榜

### 5.1 结构与可见度

- **一个圈子 = 一个「家」**（可建多个：家人/情侣/室友），成员 ≤6，每人有头像与共享名片。
- 页面顶部：成员头像行（点头像看/改 TA 能看到我什么）+ 两个分段：**动态** / **排行榜**。
- **可见度按项授权（默认最保守）**：

  | 项 | 默认 |
  |---|---|
  | 今日总额 | 开 |
  | 分类构成 | 开 |
  | 周报与头衔 | 开 |
  | 单笔明细 | **关** |
  | 小票全文 | **关** |

  未授权项在群里显示 `¥ ···`，不显示金额也不显示商户。
- **动态（群聊流）**：成员每天自动发一条「日小票卡」（按授权脱敏）+ 可点赞/表情/一句回复；系统消息（周报出炉、成就、榜单）也是气泡。
- **撤回**：关掉某项后历史消息立即脱敏（本地模型即时生效）。

### 5.2 排行榜

- **周期**：自然周（周一 00:00 重置），卡头写「10/26–11/1 · 第 43 周」。
- **四个榜，横向切换（分段或 chip）**：

  | 榜 | 指标 | 排序 | 说明 |
  |---|---|---|---|
  | 本周支出最少 | 本周支出总额 | 少 → 多 | 只看已授权「今日总额」的成员；零消费标「钱包休眠」 |
  | 本周支出最多 | 本周支出总额 | 多 → 少 | 纯陈述，不出现「超标」「浪费」等评价词 |
  | 连续记账 | 连续有账目的天数 | 多 → 少 | 当天有 ≥1 笔即续签；断签不清历史最长，最长记在徽章 |
  | 徽章墙 | 本周新得徽章数 | 多 → 少 | 徽章来自 `BadgeCatalog` / 周报头衔 |

- **榜单行**：名次（1/2/3 用 `Accent`，其余 `InkTertiary`，等宽）+ 32dp 首字母头像（无照片，`Fill` 底 + 姓名首字）+ 名字（「我」加 `AccentSoft` 底标签）+ 右对齐指标值（17/600 tnum；支出类前缀 `¥`）+ 一行小字（如「12 笔」或「最长 21 天」）。自己那行整行 `AccentSoft` 淡底。
- **样本门槛**：**参与人数 <3 → 不出榜**，位置换成一行说明「本周只有 2 人记账，凑够 3 人再发榜」+ 邀请入口；未授权可见总额的成员显示「未共享」且不参与排名。任何跨圈子/门店聚合榜沿用 SPEC D9：**样本 <20 不展示**。
- **隐私红线**：榜单只排「总额」与「连续天数」，**永远不排单笔明细、不显示他人商户名**；榜单数据不进 B 端。
- 点任意一行展开该成员的「本周 3 枚徽章」chip（emoji + 名称）与获取条件；不再另铺徽章模块。
- 空榜（周一至周二常态）：一行「本周刚开始，先记一笔」+ 灰填充「去记一笔」。

### 5.3 小游戏（`SPEC` §5 的三个模板）

- 入口：圈子页「游戏」卡片（一颗入口，不铺三张卡）；参与后回执一行「你的选择：送小料」。
- 只做「二选一大作战」P0；「猜价格」「开店一周」为「即将上线」灰态。
- **游戏表态与真实交易分开存、分开标注**，每页底部一行「娱乐，不构成建议」；不发任何现金激励，可换徽章。
- 商家侧看到的永远是聚合选择分布 + 样本量，`<20` 置灰（§6）。

## 6. 小店版 = 整机模式

- 全局状态 `AppMode { User, Merchant }`，持久化；**不是跳一个页面**，而是换整个外壳：导航、落地页、配色（B 端用墨绿 `#2F6B57` 做 accent）、文案（「顾客」不说「用户」）。
- 进入：我的 →「切换到小店版」→ 1 屏说明（数据全是演示）→ 概览。
- 退出：小店版「我的」→「回到用户版」。
- B 端导航：概览（今日客流/客单/回头客）· 洞察（人群画像）·〔发起实验〕· 结果 · 我的。

## 7. AI：模型与边界

- **模型**：`deepseek-v4.1-flash`，只经 QMuse 云函数调用；key 只存平台 secret（`cloud set-secret`），App/Web 代码里永不出现。
- **调用点只有三处**：① 一句话/语音解析兜底 ② 对话回答 ③ 周报/统计页文案（含 §3.3 的 AI 小结卡）。其余（统计、分类、日历、排行）全部本机。
- **降级链**：L0 规则 → flash → 模板文案。任何一层超时 2s 直接下探，不转圈；模板也写不出就隐藏卡片。
- **费用**：按 token 计费，单句解析成本极低但**不是零**；需要 tt 提供 key 并充值，设每日上限（默认 200 次/人/天），超限静默降级。
- **规则包** `shared/ai-rules/`：persona / guardrails / categories / parse-corpus / templates / titles，中英各一套，改规则必跑语料测试。

## 8.5 不许「全是文字标题 + 文字标签」（2026-10-28 tt 追加）

一屏如果只有「标题 + 一行说明 + 一排文字标签」，就是失败。可执行的要求：
- 每个信息块至少有一个**非文字锚点**：emoji/图标块、数字大号字、迷你图、纸片/卡片形状、进度条；
- 分类、状态、金额都用「图标 + 数字」表达，文字只做注解，且注解 ≤1 行；
- 同一屏的视觉元素类型 ≥3 种（图标 / 数字 / 图形 / 纸面质感），否则重排；
- 判据很简单：**眯眼看截图，能不能不看字就知道这块在说什么**。不能就改。
