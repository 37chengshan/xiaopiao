## 1. 设计语言：Apple 系统式（不是"拟物"，也不是"渐变"）

- **底色用系统灰白**：浅色分组底 `CanvasGrouped` `#F5F5F7`、卡片纯白 `Card`；深色底 `#000000`、卡片 `#1C1C1E`。暖纸只出现在**小票纸本身**（`Paper`），App chrome 全部中性。
- **两套风格整机可切换**（我的 → 外观）：**Apple**（系统灰白 + Action Blue `#0066CC` 作 accent）与 **Claude**（奶油底 `#FAF9F5` + 珊瑚 `#CC785C`）。切换只换 palette 与 type，不改布局；两套都必须能看。
- **accent 只做三件事**：文字链接、分段/选中的下划线、图标与数值的强调。**accent 不填充按钮、不做大面积底色。** 朱砂红降级为**印章专用**（`Stamp`）。
- **按钮只有两级**：
  | 级别 | 外观 | 用在哪 |
  |---|---|---|
  | 实心 | `Primary` 墨黑 `#1D1D1F` 底 + `OnPrimary` 白字，胶囊，高 48–52dp | 每屏 ≤1 个的主行动（保存、确认、开始打印） |
  | 系统灰填充 | `Fill` `#EDEDF0` 底 + `Ink` 字，胶囊，高 44–48dp | 次级动作（取消、跳过、筛选、重置前的备选） |
  文字链接（accent、无底色）与分段控件不算层级。**无描边、无渐变、无内高光、无投影**；手感靠按压 scale 0.96 + 变暗 100ms + 触感 + 弹簧回弹。
- **语义色**：`Negative` `#D70015`（红）、`Positive` `#248A3D`（绿）、`Warning` `#B25000`（橙）、`Info`（= accent）；只做浅底深字的图标块与差额文字，不做整块底色。
- **层次来源**：底色差 + 留白 + 字重。阴影只给浮层（导航胶囊、sheet、打印条），两档就够。
- **圆角一套**（`XpRadius`，Apple / Claude）：小 8 / 10、卡 11 / 14、大 18 / 20、浮层 28、导航胶囊 32、主键 圆形；**同一层级同一值**，不临时写 `RoundedCornerShape(17)`。
- **动效**：默认临界阻尼弹簧（response ≈0.35s）；浮层可拖动关闭、速度投影；tab 切换零位移（淡入 120ms）；尊重「减少动态效果」。

## 2. 信息架构与导航：左胶囊 + 右独立圈子（v5）

```
首次打开 → 引导（价值 / 手势与打印 / 数据底线）→ 落到「记账」
默认态： [ 记账 · 统计 · ＋记一笔 · AI ]        ( 圈子 )
圈子态： [ 记账 · ＋ ]      [ AI · 圈子 · 游戏 ]  ← 右侧胶囊展开并滑向中间
小店版： [ 今日 · 营收 · 分析 · 我的 ]           （整机模式，见 §6）
设置   = 每个根页右上角齿轮 → 独立页面
```

| 位置 | 名称 | 内容 | 备注 |
|---|---|---|---|
| 左胶囊 1（默认落地） | 记账 | 汇总条 + 日期分组账单（§3.2） | 右上角：小票图标（打印）、齿轮 |
| 左胶囊 2 | 统计 | 收支报表（§3.3） | 右上角同一颗小票图标 |
| 左胶囊 3 | ＋ 记一笔 | **动作，不是页面**：点 = 手动表单，长按 = 语音 | 与其它格同尺寸（64dp 槽、24dp 图标），无填充、淡色，下方 10sp「记一笔」 |
| 左胶囊 4 | AI | 类 GPT 对话（§3.4） | 左上角抽屉按钮管会话 |
| 右侧独立圆 | 圈子 | 群聊流 + 游戏（§5） | 点击后进入「圈子态」 |

- **圈子态动画**：左胶囊中间三格收起，只留「记账 ＋」；右侧圆展开成「AI · 圈子 · 游戏」胶囊并向中间滑（尾部留白 0.55 格）；退出时反向。全程弹簧，可被打断。
- **根页一律没有大标题**：没有整条顶栏，只有顶部一层淡渐隐；左上 / 右上各是一颗悬浮液态玻璃胶囊（44dp 高），里面是 40dp 无底色图标位（返回 / 卡包·搜索 / 小票·设置 / 「＋ 新建」「跳过」这类文字动作）。全 App 只有这一种顶部样式（tt 2026-10-29）。
- **内容要穿到胶囊底下**：玻璃靠采样页面才成立，所以 bar 的高度只能作为滚动容器的 `contentPadding`（或滚动内容里的顶部间距），不能加在滚动容器外层——外层留白会让内容停在胶囊下面，玻璃里什么都没有。
- **导航胶囊**：半透明材质（`Card` 94% / 深色 `Surface2` 94%），高 64dp，圆角 32；选中 = accent 图标与文字，未选中 `InkSecondary`。
- **打印入口只在顶栏**：「记账」「统计」右上角同一颗小票图标（`Icons.Outlined.ReceiptLong`）。
- **设置页**：分组列表，每项一行标题，最多一行灰字；外观 / 音效震动 / 默认记账方式 / 通知自动记账 / 数据与隐私 / 语言 / 切换到小店版 / 重看引导 / 关于。

## 2.5 开屏图标动画（tt#57，参考 Muse 的开屏）

- 冷启动：Android 12+ `SplashScreen` 动画图标（AVD ≤1000ms）：小票 logo 的打印口吐出一截纸条、纸条上闪过当天合计。
- 衔接：进入 App 后同一张纸条做共享元素过渡，缩小飞到右上角**常驻小票控件**的位置落定（≈300ms 弹簧），把「打印」这个概念在第一秒就教给用户。
- 总时长 ≤1.2s；任意点击跳过；热启动不播；「减少动态效果」时只做淡入。
- Web：同一段动画用 CSS / Lottie 等价实现（首屏不阻塞加载）。

### 3.1 常驻小票控件 + 小票页（v5.1，tt#56/57）

**常驻小票控件**（取代「小票图标」）
- 位置：记账 / 统计 / AI / 圈子 四个根页**右上角同一位置**常驻（齿轮左边），一眼就能找到。
- 外观：一截拟物迷你纸条（约 28×36dp）：暖白纸、下沿锯齿、纸上一行等宽小字显示今日合计（如 `¥18.28`），零消费日显示 `¥0`；不是平面 icon。
- 点按：**直接打印今天** → 打印覆盖层（下方「打印仪式」），不经过设置。
- 长按：进小票页。今日数字变化时纸条轻轻「吐出」一下（2dp 位移 + 弹簧）。

**打印仪式**（覆盖层，点控件即触发）
- 纸从控件位置的小打印机出纸口逐行吐出（声音 + 每行轻震动）→ 合计滚动 → AI 点评（读 §7.6 缓存）→ 印章盖下 → 底部「撕下分享」/「小票设置」。

**小票页**（长按控件 / 打印完成后的「小票设置」进入）
- 顶部：**拟物打印机**大图（机身、出纸口、指示灯），点机身上的打印键 = 按当前设置打印，仪式感最完整的版本在这里。
- 日期：横向日期条 + 日历，可以选**之前任意一天**重印（无账的日子印「钱包休息」）。
- 主题色：纸色 / 墨色预设（经典热敏、牛皮纸、薄荷、樱花、夜间黑纸白字）+ 自定义墨色；预览实时变。
- 打印内容开关：逐笔明细 / 合计 / 分类占比条 / AI 点评 / 头衔印章 / 本周对比 / 条码流水号；完整 / 简版两套预设一键切。
- 设置自动保存，下次点常驻控件按这个设置打印。
- 关闭后回原页、原滚动位置；21:30 推送直接进打印仪式。

## 4. 记一笔

### 4.1 三条入口，一个确认卡

| 入口 | 默认？ | 行为 |
|---|---|---|
| 手动表单（点中间主键 / 长按后手打） | ✅ 默认 | 底部 sheet：金额大字 + 支出/收入切换 + 日期时间 + 分类 5 列九宫格 + 备注 + 数字键盘（含「再记一笔」），2 次点击完成 |
| 一句话（文字） | 否 | 输入「午饭 32 骑车 2」→ L0 解析 → 一笔或多笔确认卡 |
| 语音 | 否（长按主键） | 系统 ASR 转写作文字，之后与一句话完全同路径 |

设置「默认记账方式」= 手动 / 一句话；**手动为默认**。表单顶部切换「手动 / 一句话」两个分段，不在这里再开语音（语音只挂在主键与对话页麦克风上）。

### 4.2 中间主键手势（点 / 长按）

- **载体**：左胶囊里的「＋」（§2，v5 起与其它格同大，不再是 66dp 凸起圆键）。它不切换页面，所以手势结束一定回到原 tab、原滚动位置。
- **轻点** → 手动表单 sheet 上滑（圆角 20，遮罩 `Scrim`）。
- **长按（约 250ms 触发）** → sheet **改为语音态**：语音条从主键位置**向左展开**到屏宽减 32dp，主键留在最右当「结束/松手」把手；展开动画 220ms 弹簧。
- **声波**：随**实时音量**起伏（RMS → 0–1，带平滑，静音时是一条呼吸线），右侧同步显示已识别到的 partial 文本，让用户知道「它听到了什么」。
- **结束**：松手 → 停止识别 → 文本进本地 L0 解析 → 确认卡（金额 + 商户 + 分类，可改）；确认卡里给「再记一笔」。
- **取消**：按住时**向上滑**超过 60–80dp 即取消（波形收成一条线 + 触感 reject），松手不入账。
- 无权限 / 识别失败：语音条内一行小字 + 「手打」按钮，不弹窗、不挡操作。
- 无障碍：主键语义「记一笔」，长按动作在无障碍菜单里暴露为「说一句」。

### 4.3 语音技术选型（不调 deepseek）

- **Android**：`SpeechRecognizer`，API 31+ 优先 `createOnDeviceSpeechRecognizer()`（端侧、免费、离线），不可用回落系统在线识别（厂商服务，仍免费）。不做自研 ASR、不上传音频到我们自己的服务。
- **Web**：`SpeechRecognition`（Chrome/Edge）可用则用，否则只留键盘麦克风；音频不出本机。
- **解析**：文本 → **本机 L0 规则**（金额/日期/分类/商户词典，中英语料 ≥100 句/语言单测）→ 只把 L0 解析不了的句子送 deepseek-flash。
- 成本控制：批量句子一次请求、输入 ≤200 字、每日调用上限、失败静默降级到「补一句备注」。

### 4.4 通知自动记账（支付宝 / 微信支付 / 微信「先用后付」）

- **机制**：`NotificationListenerService` 读通知 → 本机 `PaymentNotificationParser` 解析 → 结构化账目（金额 / 商户 / 时间 / 来源）→ 账单行显示「通知自动」chip。原文不出手机。
- **覆盖**：支付宝付款、微信支付付款；新增**微信「先用后付」**（如服务分先享后付的扣款通知）。调研已产出：`docs/research/wechat-deferred-pay.md`（机制、通道实测、文案不可枚举的证据）；只在文本出现「先享后付 / 先用后付 / 支付分」+ 金额时记账，纯「扣款成功」不猜。
- **连接保活（2026-10-29 真机实测新增）**：listener 被系统解绑时静默失效。设置 → 自动记账「通知读取」显示 `已连接 / 未连接 / 未开启`；未连接时给一行「重新连接」（内部 `NotificationListenerService.requestRebind()`，不改权限）。ROM 侧仍需用户白名单（后台高耗电、自启动），App 无法自行提权。
- **测试流程**（测试机没装微信 / 支付宝，tt#50/51）：
  1. **语料单测**：每种通知 ≥10 条真实格式样本（中英各一套）进 `PaymentNotificationParserTest`。
  2. **假应用**：单独的测试 APK，包名伪装 `com.tencent.mm` / `com.eg.android.AlipayGphone`，只用来发和真应用格式一样的通知；只装测试机，发布包不含；**装真应用前必须先卸载假应用**。
  3. **真实样本**：有机会时用 `adb shell dumpsys notification --noredact` 采集，脱敏后补进语料。

## 5. 圈子 = 家人共享 + 排行榜

### 5.1 结构与可见度

- **一个圈子 = 一个「家」**（可建多个：家人/情侣/室友），成员 ≤6，每人有头像与共享名片。
- 页面顶部：**v5 删除**成员头像行 / 「谁能看到什么」/ 游戏卡整块（tt#35）；页面就是群聊流，成员与可见度入口收进右上角菜单（待重新设计）。我的消息靠右，小票卡可点开（tt#27）。
- **可见度按项授权（默认最保守）**：

  | 项 | 默认 |
  |---|---|
  | 今日总额 | 开 |
  | 分类构成 | 开 |
  | 周报与头衔 | 开 |
  | 单笔明细 | **关** |
  | 小票全文 | **关** |

  未授权项在群里显示 `¥ ···`，不显示金额也不显示商户。
- **动态（群聊流）**：成员每天自动发一条「日小票卡」（按授权脱敏）+ 可点赞/表情/一句回复；系统消息（周报出炉、成就、榜单）也是气泡。
- **撤回**：关掉某项后历史消息立即脱敏（本地模型即时生效）。

### 5.2 排行榜

- **周期**：自然周（周一 00:00 重置），卡头写「10/26–11/1 · 第 43 周」。
- **四个榜，横向切换（分段或 chip）**：

  | 榜 | 指标 | 排序 | 说明 |
  |---|---|---|---|
  | 本周支出最少 | 本周支出总额 | 少 → 多 | 只看已授权「今日总额」的成员；零消费标「钱包休眠」 |
  | 本周支出最多 | 本周支出总额 | 多 → 少 | 纯陈述，不出现「超标」「浪费」等评价词 |
  | 连续记账 | 连续有账目的天数 | 多 → 少 | 当天有 ≥1 笔即续签；断签不清历史最长，最长记在徽章 |
  | 徽章墙 | 本周新得徽章数 | 多 → 少 | 徽章来自 `BadgeCatalog` / 周报头衔 |

- **榜单行**：名次（1/2/3 用 `Accent`，其余 `InkTertiary`，等宽）+ 32dp 首字母头像（无照片，`Fill` 底 + 姓名首字）+ 名字（「我」加 `AccentSoft` 底标签）+ 右对齐指标值（17/600 tnum；支出类前缀 `¥`）+ 一行小字（如「12 笔」或「最长 21 天」）。自己那行整行 `AccentSoft` 淡底。
- **样本门槛**：**参与人数 <3 → 不出榜**，位置换成一行说明「本周只有 2 人记账，凑够 3 人再发榜」+ 邀请入口；未授权可见总额的成员显示「未共享」且不参与排名。任何跨圈子/门店聚合榜沿用 SPEC D9：**样本 <20 不展示**。
- **隐私红线**：榜单只排「总额」与「连续天数」，**永远不排单笔明细、不显示他人商户名**；榜单数据不进 B 端。
- 点任意一行展开该成员的「本周 3 枚徽章」chip（emoji + 名称）与获取条件；不再另铺徽章模块。
- 空榜（周一至周二常态）：一行「本周刚开始，先记一笔」+ 灰填充「去记一笔」。

### 5.3 小游戏（v5：独立入口，≥8 个）

- 入口：圈子态右侧胶囊的「游戏」格 → 全屏 `GamesHub`（同 tab 内、带返回）；圈子流底部也保留一颗「游戏」卡片作为第二入口（tt#37）。
- 内容与引擎分离：`domain/games/GameContent.kt` 存 8 个游戏的数据（题目、选项、分档/人格/雷达轴、时间），
  `ui/games/GamePlayer.kt` 一个播放器渲染全部题型（单选、二选一、量表、猜价、区间、判断题、任务）并负责进度、反馈与结果页。加游戏只改内容，不改播放器。
- 现在 8 个：钱包人格测试（14 种结果）、消费二选一（30 题）、小票猜猜看（10 题猜价）、盲盒猜价（8 题区间）、
  今日小任务（20 条池子随机抽 10 条）、省钱大挑战（8 幕情景）、记账冷知识（15 道判断）、花式花钱雷达（5 题量表 → 五维雷达）。
- **游戏表态与真实交易分开存、分开标注**；每页一行「娱乐，不构成建议」；不出推荐购买/比价/理财结论；不发任何现金激励，后续可换徽章。
- 商家侧的「二选一大作战」实验与这里的 C 端娱乐游戏是两套数据；商家只看聚合分布 + 样本量，`<20` 置灰（§6）。

### 5.4 圈子管理与成员体系（tt#22）

| 项 | 规则 |
|---|---|
| 命名 | 建圈时自定义名称（≤12 字），圈主随时可改；改名前后的历史消息保留 |
| 加入方式 | **邀请码**（6 位，大小写不敏感，24 小时有效、最多 10 次）；**二维码**（内容就是同一条邀请链接/码，扫码直接进确认页） |

### 5.5 卡包：银行卡 + 会员卡（tt#57）

- **入口**（tt#58）：记账页**左上角**卡包按钮（小卡片图形，与右上角小票控件对称；AI 页左上角仍是会话抽屉）。
- **不铺满**（tt 2026-10-29）：卡包是浮层卡片，不是全屏面板——左右留 12dp 边、顶部从状态栏下 4dp 起、底部留 96dp 露出页面（导航胶囊仍在下面）。从左上角卡包按钮的位置长出（弹簧，`XpMotion.bouncy`，缩放 0.12→1，可被打断），背后是系统跨窗口模糊 + 一层浅遮罩；点卡片外面或向下拖 96dp 关闭。卡片自带 `FLAG_SECURE`（Dialog 独立窗口，含最近任务快照）。
- **展开动效**（照参考录屏 16.2–16.8s 的卡包，形态改成浮层卡片）：面板里卡片**层叠堆放**——每张只露出约 40dp 的标题条（名称左、数值右），最后一张是完整大卡，下面接「我的卡」列表；面板落定时卡片跟随轻微上移归位（错峰 30ms）。点某张卡 → 它升起成完整卡面、其余卡下沉收拢（类 Apple Wallet）；下滑 / × 关闭。**不学**参考里的闪黑和「先出占位列表再换成卡片」。
- **面板结构**（量自 `references/wallet-app-2026-10-28/cardwallet_full_redacted.jpg`，tt#59）：顶部 × + 一行「本月卡上支出」与眼睛（隐藏金额）+ 大数字；卡片区左右边距 12dp、圆角 16dp，每张后面的卡露出 **约 71dp** 标题条（左：卡名 20sp/600；右：本月支出 + 一行 13sp 小字如「尾号 1234 · 信用卡」）；**最前一张是完整卡面约 200dp 高**：卡面预设色 / 暗纹、右下角卡组织字样、左下一行提醒（如「3 天后还款日」）；卡片下方白卡「卡详情」：尾号（可复制）、本月支出与笔数、账单日 / 还款日、最近 5 笔。参考配色只作卡面预设灵感（青 `#74E2EF`、黄 `#F9F65B`、橙 `#F7CB50`、黑 `#161618`），不照搬其品牌。
- **添加卡**：① **拍照识别**（CameraX + ML Kit 文字识别，全程本机）；② **手动输入卡号**；③ 选**卡面预设**（6 款：墨黑、雾蓝、薄荷、珊瑚、香槟金、极光；可选是否显示银行名）。卡号输入后用本机 BIN 表识别银行与卡种，自动带出默认卡面。
- **银行卡**（tt#60）：保存 银行名 / 储蓄或信用 / **完整卡号（加密）** / 自定义名称 / 卡面；信用卡可填账单日、还款日 → 提前提醒。
  - **卡号加密**：Android Keystore 生成的 AES-256-GCM 密钥加密后落盘（密钥不可导出），明文只在显示时解密到内存；Web 端不存卡号（只显示尾号）。
  - **显示**：默认 `•••• •••• •••• 1234`；点眼睛 → 系统生物识别 / 锁屏密码验证（`BiometricPrompt`，允许设备凭据）→ 显示完整卡号，30 秒或离开页面后自动重新遮住；旁边复制按钮（复制后 60 秒清剪贴板，Android 13+ 标记敏感内容）。
  - **不存**：有效期、CVV、密码；不查余额、不做支付。
  - **不出本机**：不进云、不进 B 端、不进分享图；卡包数据**排除在系统自动备份之外**（`dataExtractionRules`）；卡包页 `FLAG_SECURE`。
  - 通知解析出的「尾号 1234」自动把账单归到这张卡上，卡详情显示本月在这张卡上的支出与笔数。
- **会员卡**：店名 / 会员号 → 展示条码或二维码（打开时屏幕亮度拉满）/ 积分或余额（手填）/ 到期提醒；可以扫码录入（相机只在本机识别）。按商户名把账单关联过来：「本月在这家店花了 ¥x」。
- **视觉**：拟物卡片叠放（类 Apple Wallet），点卡展开、下滑收回；卡面颜色是这一处允许的大面积色块。
- **隐私**：卡包数据只在本机加密存储（EncryptedSharedPreferences / Room + SQLCipher 二选一）；卡包页 `FLAG_SECURE`（禁截屏、最近任务里打码）；可选生物识别解锁；不进云、不进 B 端。
- 产品原则：只记录与提醒，不推荐办卡、不比较权益、不给理财结论。

## 7. AI：模型与边界（v5：commandcode 免费模型，后台自动选）

- **Provider**：commandcode（OpenAI 兼容 `/chat/completions`，base `https://api.commandcode.ai/provider/v1`）。**只用免费模型**，tt 不付费（tt#39/52）。
- **用户不选模型**：界面上没有任何模型选择；后台有一个「模型路由」按顺序尝试，失败就换下一个，全部失败回落本机规则引擎。
- **候选与顺序**（2026-10-28 实测，都支持 tool calling）：

  | 顺序 | 模型 id | 实测 | 用途 |
  |---|---|---|---|
  | 1 | `reflection/beam:free` | 文字 2.0s，工具调用 3.9s，中文解析正确 | 对话、一句话解析 |
  | 2 | `stealth/glyph-cluster:free` | 文字 6.8s，工具调用 9.0s，结果正确 | 1 失败 / 超时时 |
  | 3 | `poolside/laguna-s-2.1-free` | 当时上游 429 | 兜底 |
  | — | 本机规则引擎 | 0 延迟 | 全部失败 / 离线 |

  免费模型会随时上下线：路由在启动时读 `/models`，只保留 id 以 `:free` / `-free` 结尾、且在候选表里的；连续失败 3 次的模型熔断 10 分钟。
- **超时**：首 token 4s、整轮 15s；超时直接换下一个，UI 不转圈，只显示工具步骤在走。
- **key 在哪**：只在云端（QMuse 云服务云函数 secret）。App / 浏览器只调我们自己的云函数 `ai-chat`，永远拿不到 key。开发期实验：本机起一个同代码的 dev 代理（key 从本机环境变量读，不进仓库），手机走 `adb reverse`。
- **请求必须带自定义 `User-Agent`**：commandcode 前面有 Cloudflare，默认 Python / 部分库的 UA 会被 403（error 1010）。
- **调用点**：① 一句话 / 语音解析兜底 ② AI 对话 ③ 周报 / 统计页文案。统计、分类、排行全部本机算，模型只写字、只经工具读数。
- **数据出端**：只发 system prompt + 工具定义 + 用户这句话 + 工具返回的**摘要**；不整表上传、不发通知原文。
- **规则包** `shared/ai-rules/`：persona / guardrails / categories / parse-corpus / templates / titles，中英各一套，改规则必跑语料测试。

## 7.5 动效与高刷（tt#13/30/48）

- 每个页面都有入场；tab 切换、设置打开、sheet、打印覆盖层都有转场；按压第一帧就有反馈（scale + 变暗），列表不整体动画（只做首屏错峰）。
- 所有逐帧动画按 `dt` 推进（`withFrameNanos`），不按帧数；90/120Hz 真机用 `adb shell dumpsys gfxinfo com.xiaopiao.app` 量 jank，<1% 才算过。
- 尊重系统「减少动态效果」。

**参考录屏拆解采纳**（`docs/references/wallet-app-2026-10-28/analysis-video.md`，omp + deepseek 60fps 逐帧，Claude 裁决）：
- **一级 tab 保留短淡入（120ms），不学参考的 0ms 硬切**：tt#27/30 明确要求页面之间有转场；只要求切换时不位移、不重排。
- tab 选中 pill 改成填满槽位的全圆胶囊（56×40dp，`Fill` 100%），选中图标 1.1 倍。
- 二级页 push：新页从右 1/4 滑入 + 淡入 220ms，底层 1/8 视差；返回 180ms `XpEase.out`；返回箭头固定，不做 × → ← 图标替换。设置子页（外观 / 数据与隐私等）先落地。
- 全屏 sheet 顶角 32dp（新增 `XpRadius.sheet`），打开约 300ms 强 ease-out、关闭约 200ms；设置列表行高 52–54dp，带副标题 76dp。
- 骨架屏推广到统计 / 圈子：切入同一帧出骨架，最短显示 200ms 防闪，不转圈。
- AI 小结卡的事实轮播：容器高度固定，上行 20dp + 淡入 170ms，停留 1200ms，只在可见且未滚动时播放。
- **不学**：转场闪黑、同一分区两套导航、动画过程中重排内容、异步纹理占位、营销式首页、44sp 巨号余额、实时毛玻璃导航、渐变卡。

## 7.6 AI 后台自动总结（tt#57）

- **什么时候生成**：账本变化后去抖 10 分钟；每晚 21:30（给小票 AI 点评）；每周一 08:00（周报）；每月 1 日（月报）。Android 用 WorkManager，Web 在打开时补算。
- **生成什么**：统计页 AI 小结卡（本期最大类目、环比方向、记账天数）、小票 AI 点评、周 / 月报一句话；全部只陈述事实，不给建议。
- **怎么生成**：数字由本机 `insights/` 算好，只把**数字摘要**交给 §7 的免费模型写成一句话；模型不可用时用本机模板；结果缓存，界面只读缓存并标「更新于 HH:mm」，从不让用户等。
- 用户可在设置里关掉「AI 自动总结」（关掉后全部用本机模板）。

| 1 | **Toast**（轻提示） | 已保存、已打印、已导出、同步完成 | 底部居中（Web 右下角）胶囊，ink 底白字 13/500 + 可选图标，2.4s 自动消失；同时最多 1 条，新的替换旧的；入场 y 16→0 + 淡入 200ms，出场淡出 160ms |
| 2 | **可撤销 Snackbar** | 删除账单、批量改分类、移出圈子 | 同 toast 位置，左文字右「撤销」accent 链接，5s；倒计时细线；撤销后反向动画恢复原位 |
| 3 | **提示条 Banner** | 通知权限没开、离线、同步失败、体验账号提醒 | 页面顶部（工具栏下）36dp，fill 底 + 图标 + 一句话 + 右侧动作链接 + ×；不自动消失，问题解决后自动收起 |
| 4 | **确认对话框** | 不可撤销操作（删除整个账本、解散圈子、删除卡片） | 居中卡片，标题一句 + 后果一句 + 灰填充「取消」/ negative 实心「删除」；不用于可撤销操作 |
| 5 | **系统通知**（仅 App） | 21:30 小票、订阅扣费提醒、信用卡还款日、圈子新周报 | Android 通知渠道分开（小票 / 提醒 / 圈子），可在设置里逐类关闭；点通知直达对应页面（小票直接进打印仪式） |
| — | **应用内消息中心**（Web 工具栏铃铛 / App 设置里「消息」） | 系统通知的历史、圈子动态汇总、周报出炉 | 列表按天分组，未读圆点；不做营销消息 |

- **震动与声音**跟随级别：0–1 轻触感；2 无；3 无；4 警告触感；打印 / 印章有专属声音与震动（§3.1）。
- **文案**：说结果不说过程（「已删除「瑞幸」」而不是「删除操作成功」）；不用感叹号；中英各写。
- **实现**：Android 统一 `XpToast` / `XpSnackbar` / `XpBanner` 组件（`ui/components/`），Web 用 sonner（toast / 可撤销）+ 自有 `Banner`；位置、时长、动效按上表，两端一致。
- 禁止：同一时刻多个 toast 堆叠；toast 里放重要错误；用对话框确认可撤销的操作。

## 8.5 不许「全是文字标题 + 文字标签」（2026-10-28 tt 追加）

一屏如果只有「标题 + 一行说明 + 一排文字标签」，就是失败。可执行的要求：
- 每个信息块至少有一个**非文字锚点**：emoji/图标块、数字大号字、迷你图、纸片/卡片形状、进度条；
- 分类、状态、金额都用「图标 + 数字」表达，文字只做注解，且注解 ≤1 行；
- 同一屏的视觉元素类型 ≥3 种（图标 / 数字 / 图形 / 纸面质感），否则重排；
- 判据很简单：**眯眼看截图，能不能不看字就知道这块在说什么**。不能就改。
