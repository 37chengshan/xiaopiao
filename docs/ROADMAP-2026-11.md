## 验收底线（之前踩过的坑）

- 每个按钮都有进行中 / 成功 / 失败的反馈；保存类先写入成功再关闭弹层；网络操作有超时和失败后的下一步（`docs/APP-DESIGN.md` §7.7）。
- 动画只动 transform / opacity；按压态跟随控件的形状（不出现长方形暗块）；阴影不能被裁切；页面切换只用两种：tab 之间左右平移，下一级页面从右侧推入。
- 360dp 和 411dp 宽、1.3 倍字体都要截图；只过编译和单测不算完成，要逐屏截图并把主路由走一遍。
- 中英双语；界面不出现「演示数据」字样；mock 在代码里保持可识别。
- key 和 token 不进代码、日志和交接文档。
