## 规则

1. 不直接复制官方 MBTI、九型 RHETI、爱之语、依恋量表等受版权/商标保护的题目和结果文案。
2. 使用 MIT/公共领域来源时保留出处；若后续引入 OpenTDB（CC BY-SA 4.0），需在应用内署名并遵守相同方式共享。
3. 任何新增游戏必须通过 `GameContentTest` 的内容约束：每个结果可达，quiz 只有一个正确答案，分档覆盖完整，结果分析不少于 3 条（新的重点测试不少于 5 条）。
4. 结果只陈述本机内容，不读取用户真实账目；游戏表态与真实交易数据分开存放。
