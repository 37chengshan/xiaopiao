# 今日小票 / Daily Slip 品牌规范

2026-10-29 定稿。品牌色与界面强调色分开：珊瑚橙只属于品牌时刻，App 界面的强调色保持蓝色，不动（tt 2026-10-29）。

## 名字

| 场景 | 写法 |
|---|---|
| 中文 | 今日小票 |
| 英文 | Daily Slip（落地页大标题、英文界面、Web 英文品牌名） |
| 一句话 | 每天打印一张会说话的 AI 小票 |
| 比赛 | 支付宝智能体涌现比赛 · Season 1（「比赛」，不是「奖」） |

## 标志

**珊瑚橙圆角方块 + 白色小票 + 撕口锯齿底边 + 三行珊瑚色打印线。** 全线只用这一个图形：

| 位置 | 文件 |
|---|---|
| Android 启动图标（adaptive） | `app/src/main/res/drawable/ic_launcher_foreground.xml` + `ic_launcher_background.xml` |
| Web favicon | `web/public/favicon.svg`（viewBox `18 18 72 72`，即 adaptive icon 的可见区） |
| Web 品牌组件 | `web/src/components/brand/BrandMark.tsx`（侧栏、落地页导航、落地页手机、404 共用） |

- 构造：108×108 画布；小票 `x 36–72, y 30–74`，底边 8 个 4.5 宽的锯齿；打印线 `y 40 / 48 / 56`，长 24 / 18 / 24，粗 3。
- 不加描边、阴影、渐变；不另画黑色小票或橙点版本（2026-10-29 已统一掉）。
- 最小尺寸 16px；小于 20px 时不放字标。
- 字标：图形右侧 8px 间距接「今日小票」或「Daily Slip」，600 字重，颜色跟随正文墨色。

## 颜色

| 名称 | 值 | 用在哪 |
|---|---|---|
| 品牌珊瑚 | `#FF6B4A` | 图标、favicon、品牌组件；小票印章等「品牌时刻」 |
| App 界面强调色 | 蓝（`XpColors.Accent`，主题可换） | 按钮、选中态、链接——**不换成珊瑚** |
| 纸 | `#F5F3EE` / 小票纸面白 | 开屏底色、小票纸 |
| 墨 | `#1D1D1F`（App）/ `#141413`（Web） | 正文、字标 |

## 图形元素

- **撕口锯齿**：小票底边、圈子里的小票卡片（`TornReceiptCard`）、分享卡。
- **热敏纸**：纸面白、浅灰打印线、等宽数字。
- **印章**：每日头衔用 `XpColors.Stamp` 的浅底胶囊。
- **液态玻璃**：只用于浮在内容上的层（导航胶囊、底栏、发帖按钮、提示条、语音条、Web 导航与选中透镜）。平铺在纯色底上的卡片不用玻璃。规则见 `docs/APP-DESIGN.md` 与 `app/.../ui/components/LiquidGlass.kt`。

## 不要做

- 不把珊瑚橙铺成 App 的大面积底色或按钮色。
- 不用「演示数据」之类的标注压在品牌元素上（测试版规则，见 `AGENTS.md`）。
- 不在标志里放 AI、闪光、机器人等符号——产品是「记录」，不是「推荐」。
