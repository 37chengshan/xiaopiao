# 商业化路线图（v1，2026-11-02）

tt：产品不只为了比赛，后面要做订阅制或买断制；目前**还没有公司主体**。本文给出分档草案、先搭的权益系统、各平台收款方式和办资质的顺序。价格只是占位，由 tt 定。标「待核实」的条目以官方文档为准。

## 1. 原则

- **订阅侦探的品牌承诺，自己先做到**：自动续费要显著提示、扣费前提醒、一键取消；退订入口不能藏。
- 本机记账永远免费且完整，付费的是「省心」和「好看」，不是把基础功能锁起来。
- AI 有持续的模型成本，所以买断里不包含无限 AI。

## 3. 权益系统（先做，不依赖收款）

- 服务端（派 omp 实现，部署前请 tt 批准）：
  - `entitlements` 表：`user_id, plan(free/pro/lifetime), source(admin/apple/huawei/wechat_mp/alipay/wechat_pay), expires_at, original_txn_id, updated_at`；
  - `GET /v1/me/entitlements` 返回当前权益和各项 AI 额度余量；
  - 先只支持管理员手动发放（内测用户、评委），各渠道的收据校验等有了主体再接。
- App 和 Web：统一用 `Feature.isEnabled(feature)` 做功能闸门，权益缓存在本机，离线也能用；**断网时不能降级用户已付费的功能**。
- 额度计量：AI 和拍照识别都在服务端计数，App 只负责展示剩余额度。

## 4. 各平台收款

| 平台 | 方式 | 抽成 / 费率 | 主体要求 |
|---|---|---|---|
| iOS | **强制 Apple IAP**（自动续期订阅 + 非消耗型买断） | 30%，小型开发者计划和第二年订阅为 15% | 个人开发者账号可以 |
| 鸿蒙 | **强制华为 IAP Kit**（收银台里含微信 / 支付宝） | 按华为协议（待核实） | 华为开发者 + 商户入网 |
| 微信小程序 | **强制虚拟支付**（2026-04-01 起，所有终端） | iOS 端 2026 年 12%；非 iOS 端标准 10%，限时 1%（待核实） | 企业 / 个体户不限；**个人主体 2026-09 起可开**（工具类目、认证、备案、月限额 10 万，待核实） |
| Android 国内 | 微信支付 / 支付宝 APP 支付；自动续费用支付宝周期扣款或微信委托代扣 | 约 0.6% 通道费 | 需要商户号（企业或个体户） |
| Web | 微信 / 支付宝网页支付 | 约 0.6% | 需要商户号 |

## 5. 主体与资质的顺序（建议）

1. **先用个人主体把小程序跑起来**：小程序认证 + ICP 备案 → 如果个人虚拟支付开得出来，就先在小程序里卖 Pro（最快验证付费意愿）。
2. **注册个体工商户**（最快、成本最低）或有限公司 → 开对公 / 经营账户。
3. 开通微信支付和支付宝商户 → 接 Android 和 Web 的收款。
4. App 备案（工信部，App 名称要和商店一致）→ 申请软件著作权（国内安卓商店基本都要）→ 上架华为、小米、OPPO、vivo 等商店。
5. Apple Developer → iOS 上架（中国区需要 ICP 备案号）。
6. 华为开发者 + IAP Kit 商户入网 → 鸿蒙上架。

每一步需要的材料和时间写进 `docs/DEPLOY.md` 的新章节，办的时候逐项打勾。

## 6. 合规清单

- 隐私政策和用户协议（上架必需）；饮食、体重、健康属于敏感个人信息，需要单独同意（PIPL）。
- 自动续费：开通页显著标明价格、周期、续费方式；扣费前提醒；退订方式清楚可用（市场监管的相关要求，待核实具体条款）。
- 未成年人：不诱导消费；游戏不发现金奖励（已在 SPEC 中定下）。
- 发票：个体户 / 公司开票能力。
