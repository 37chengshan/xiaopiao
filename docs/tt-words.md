## 已定结论（沉淀，随原话更新）

1. 导航：默认左胶囊 **记账 · 统计 · ＋记一笔 · AI**，右侧**独立**圆圈「圈子」；点圈子后左胶囊收起只剩 **记账 ＋**，右侧展开 **AI · 圈子 · 游戏** 并滑向中间。设置 = 每页右上角齿轮 → 独立页。
2. 记一笔：点 = 手动表单；长按 = 语音（系统 ASR），悬浮球已删除。
3. 打印：记账页右上角小票图标 → 打印页；不设常驻打印按钮。
4. 文案：界面不出现「演示数据」字样；不写内部语言。
5. 按钮：只有两级（实心 / 系统灰）；实心为墨黑，不用蓝填。选中态用 accent。
6. AI：类 GPT 多轮；左上抽屉管会话；回答前有工具步骤（可读结果）、流式输出、周期问题附图表卡。
7. 圈子：群聊 + 可点开小票 + 自己的消息靠右；游戏独立入口；成员/邀请码/圈主管理员/圈内昵称见设计文档 §5.4（UI 待做）。
8. 分享：左「完整/简版」收窄分段 + 右「保存图片」；下面一行图标+小字。
9. 性能/动效：所有页面都要有入场与转场，按压第一帧反馈，列表不整体动画。
10. 双语：App 与 Web 都要中英双语，英文是必备项（tt#40/41）。
11. 云端模型：只用 commandcode 的**免费模型**，后台自动选择与降级，用户不选模型；key 只在云端（tt#39/52）。
12. 记账方式：设置里可选默认方式（手动 / 一句话）；语音 = 长按「＋」走系统 ASR（tt#46，tt#4 取代 tt#47）。
13. 通知识别：支付宝 / 微信支付，加微信「先用后付」；测试用只装在测试机的「假应用」（tt#50/51）。
14. 小票：打印动画与纸面建模继续打磨；分享「完整 / 简版」必须一眼看出不同（tt#49）。
