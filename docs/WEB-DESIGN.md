# 今日小票 · Web（桌面端）设计 v1

日期：2026-10-28。依据：tt#61–62（`docs/tt-words.md`）。**取代** `web/BRIEF-WEB.md` 里「手机优先、首屏即任务、不做 landing」的旧定位，以及 2026-10-28 合入的 WP6「手机胶囊导航搬到 Web」（那一版只作过渡）。
产品原则、数据底线、视觉语言（Apple 系统式、按钮两级、无渐变）与 `docs/APP-DESIGN.md` 一致；本文只写 Web 特有的部分。

## 0. 定位

| | 手机 App（Android） | 桌面 Web |
|---|---|---|
| 用户 | C 端为主（每天记、每天打印小票） | C 端回顾与整理 + **B 端经营后台（主力）** |
| 擅长 | 自动记账（读通知）、随手记一笔、打印仪式、卡包 | 大表格批量编辑、CSV 导入导出、大图表、长对话分析、小店经营 |
| 数据 | 本机为主，登录后同步结构化字段 | 云端账号数据（与手机同一账号） |
| 比赛 | 视频高光 | **评委入口**（QMuse 链接） |

## 1. 账号与同步（tt#62：账号登录）

- **账号**：手机号或邮箱注册 / 登录（QMuse 云服务认证）。手机 App 与 Web 用同一账号。
- **同步什么**：账目结构化字段（金额 / 商户 / 时间 / 分类 / 来源 / 备注）、小票设置、圈子、小店营收与实验。
- **不同步**：通知原文与截图（只在手机本机解析）、**银行卡完整卡号**（Web 只显示尾号）、会员卡码。
- **怎么同步**：每条记录带 `id + updatedAt + deviceId`，按记录 last-write-wins；手机离线时本机排队，联网后补传；删除用软删除标记。顶栏显示「手机 2 分钟前同步」。
- **手机端开关**：手机 App 默认本机使用，登录并打开「同步到电脑」才上传（单独授权、可随时关闭并删除云端数据）——符合数据底线。
- 需要 QMuse 云服务：认证 + 数据表（`transactions`、`receipt_prefs`、`circles`、`circle_members`、`merchant_revenue` 等）+ 按用户的行权限。**初始化、建表、导入都要 tt 批准后执行。**

## 2. 立即体验（tt#62）

- Landing 主按钮「立即体验」→ 自动创建一个**访客账号**，复制一份预置账本（约 60 天账单、2 个圈子、小店 30 天营收），每个访客互不影响。
- 界面**不加演示标注**（tt#54）；右上角常驻一条轻提示：「下载 App，登录同一账号即可同步」+「下载 App」+「登录 / 注册」。访客账号可以一键升级成正式账号（保留数据）。
- 访客账号 7 天无访问自动清理。
- 「下载 App」指向 GitHub Releases 上的 APK（**发布 Release 是外部动作，需要 tt 批准**）。

## 3. Landing 页（`/`）

面向评委与新用户，一屏讲清楚、第二屏能上手。按 taste-skill 做，避免模板感。

| 区块 | 内容 |
|---|---|
| Hero | 一句话「每天一张会说话的小票」+ 拟物打印机实时吐出一张小票的动画（与 App 同一套纸面）；按钮：立即体验（实心）/ 下载 App（灰填充） |
| 三步 | 自动记账（读通知）→ 每天打印小票 → 圈子与周报，每步配一张真实界面截图 |
| 小店 | 「给楼下小店老板」：营收导入、经营日报、顾客聚合洞察，配后台截图 |
| 隐私 | 三条承诺：原文不出手机 / 贡献默认关闭单独授权 / 只给聚合（样本 <20 不展示） |
| 收尾 | 再一次「立即体验」+ 二维码下载 App |

## 4. 内部功能页（`/app/*`，桌面布局）

**外壳**：左侧边栏（可折叠，220dp）+ 顶栏 + 主内容区（最大宽 1280，12 栏栅格）。
- 顶栏：全局搜索（⌘K 命令面板）、同步状态、**常驻小票控件**（与 App 同概念，点击打印今天）、体验提示 / 头像。
- 侧边栏分两组，顶部「个人 / 小店」切换：

| 个人（C） | 内容 |
|---|---|
| 总览 | 今日 / 本月 KPI、趋势图、AI 自动总结卡、最近账单、本周圈子动态 |
| 账单 | 桌面大表格：搜索、组合筛选、多选批量改分类 / 删除、行内编辑、CSV 导入（拖拽）/ 导出 |
| 统计 | 周 / 月 / 年 / 自定义，大图表（与 App §3.3 同口径），可并排对比两期 |
| AI 助手 | 宽版对话，右侧面板显示图表卡与引用的账单 |
| 小票 | 小票工作台：打印机拟物 + 历史日期 + 主题色 + 内容开关；**支持浏览器打印到真实热敏打印机（58 / 80mm 版式）**与导出图片 |
| 圈子 | 群聊流 + 成员与可见度管理（桌面更好管理） |
| 卡包 | 只读尾号与本月卡上支出（完整卡号不上云） |
| 设置 | 账号、已登录设备、同步、数据导出 / 删除、语言 |

| 小店（B，桌面主力） | 内容 |
|---|---|
| 经营总览 | 今日 / 本周营收、订单、客单价、同比环比、14 天趋势 |
| 营收 | 日账大表格，CSV / Excel 拖拽导入（预览、查重、批量改），手动补录 |
| 分析 | 多维图表（按星期 / 时段 / 品类）、AI 自动总结（只陈述事实） |
| 日报 | 经营日报小票，打印 / 导出 |
| 顾客洞察 | 聚合人群（样本 <20 不展示）、发起实验、看结果 |

- 桌面交互：快捷键（N 记一笔、/ 搜索、P 打印、⌘K）、拖拽导入、表格键盘导航、右键菜单、hover 预览。
- 响应式：≥1024 完整布局；768–1024 侧边栏折叠成图标；<768 提示「手机上用 App 体验更好」，同时仍可用。

## 5. 视觉与动效

- 与 App 同一套 token（Apple 系统式，Inter + 系统中文），桌面字号上调一档（正文 15 / 表格 14）。
- 动效：侧边栏切换内容区淡入 + 4px 位移；表格行增删动画；图表错峰生长；小票打印同一套拟物动画。
- 中英双语（tt#40/41），设置与 Landing 右上角可切。

## 6. 实施顺序（建议）

| 步 | 内容 | 依赖 |
|---|---|---|
| W1 | Landing 页 + 桌面外壳（侧边栏 / 顶栏 / 路由 `/app/*`），先接现有本机数据 | 无 |
| W2 | 总览 / 账单（大表格 + 搜索筛选 + CSV）/ 统计 | W1 |
| W3 | 小店后台（经营总览 / 营收 / 分析 / 日报 / 洞察） | W1 |
| W4 | QMuse 云服务：认证 + 数据表 + 访客账号 + 预置数据 | **已完成（2026-10-28，`d2b07f0`）**：见下方 W4 实现说明 |
| W5 | 手机 App 登录 + 同步 | W4 |
| W6 | AI 助手接云（免费模型路由）、小票工作台、圈子、卡包只读 | W4 |

### W4 实现说明（2026-10-28，tt 批准「云服务可以建」后实施）

- **账号**：QMuse 云服务只支持 QMuse 平台登录（custom-token）与匿名会话，**不支持自建手机号 / 邮箱注册**；§1 的「手机号或邮箱注册」改为 QMuse 账号登录。未登录的访客 = 匿名会话。
- **表**：`transactions`（账单）、`merchant_revenue`（小店营收，暂无 Web 界面，Service 已就绪）、`receipt_prefs`（打印音效 / 震动）；每行带 `ownerId`。圈子等表等对应页面做出来再追加（Schema 只能 append）。
- **预置数据（tt 选定）**：访客的预置账本只在浏览器内存生成，与访客自己记的账合并显示；只有用户自己的账写入云端，云端不混入虚构数据。登录用户不显示预置账本。
- **权限（待 tt 在 QMuse「数据表权限设置」里改）**：平台默认 READ = 所有人。三张表都要把 READ 改为「创建者」，EDIT / DELETE 保持「创建者」；改之前其他用户理论上能读到别人的行（代码按 `ownerId` 过滤，但这不是安全边界）。
- **限制**：列表每页最多 20 条、只能按创建时间倒序；账本读取最近 400 天、逐页拉取。匿名访客登录后数据不会自动迁移到正式账号（§2「一键升级保留数据」待做）。
- **启动代码**：QMuse import 不允许 `main.tsx` 有初始化调用，且会替换 `__root.tsx`；全局启动逻辑放在 `src/routes/_app.tsx`。合并 `web/shell` 时注意保留。
