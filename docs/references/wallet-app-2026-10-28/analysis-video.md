# 参考录屏拆解：交互 · 转场 · 组件尺寸

素材：`video_20261028_062914.mp4`（16.83 s，1080×2400，94 fps 高刷录屏，状态栏带录屏计时徽标）。
参考对象是 ZA Bank（香港）App 的一次真实操作；**只取模式，不取品牌、插画、文案、色板**。

## 0. 方法与精度

| 项 | 做法 |
|---|---|
| 看片 | 先看 6 张联系表（4 fps，f_001–f_067）定位每一次交互；再对 12 个转场窗口单独抽出 60 fps 序列（`dense/T1…T11`），逐帧比对 |
| 时间 | 4 fps 帧 N 的时刻 = (N−1)×0.25 s；60 fps 序列按 `-ss` 起点 + 帧序换算。源片 94 fps，单帧 ≈ 10.6 ms，**所有时长按 ±17 ms 计** |
| 判读 | 逐帧灰度均值 + 相邻帧绝对差（0–255）。「单帧跳变」= 内容在 ≤17 ms 内整体替换（无动画）；「连续衰减」= 真实动画 |
| 尺寸 | 1080 px ÷ 3 ≈ 360 dp，本文所有 dp/sp 为**估计值**，圆角/边距 ±2 dp，字号 ±1 sp（以字形像素高反推，CJK 字面高 ≈ 0.88 em） |
| 颜色 | 直接对解码后的像素取样，JPEG 误差 ±3/255 |
| 读图 | 全部图像均为本机 ffmpeg 抽帧后逐张打开；证据帧保存在 `…/scratchpad/omp-ref/{sheets,dense,full,crop}`（不在仓库内） |

## 2. 转场与动效逐条

### A. 一级 tab 切换 = 零动画（最值得记的一条）

- 类型：**内容硬切**，无淡入、无位移、无共享元素。
- 时长：**≤17 ms**（灰度差在两帧之间由 0.2 直接跳到 29.8，前后帧均为 0.2–0.8）。
- 缓动：不适用。
- 错峰：无。内容与底部导航**同一帧**替换（1.88 s）。
- 结论：整套「有质感」的感觉来自 ① 静止页面本身的对齐/留白 ② sheet/push 的三段动效；**tab 之间一段过渡都不给**。

### B. 按压反馈（tab/图标）

- 类型：**圆形 ripple 扩散**（半径约 24 dp），图标颜色转为强调绿；**不做 scale**。
- 时长：约 250–300 ms（只能采到 1 帧，属推断）。
- 错峰：先色变，后 ripple 扩散；同组其他 tab 完全不动。

### C. 全屏 sheet 打开（我的）

- 类型：黑色遮罩瞬变（≤17 ms 到底）+ 面板自底部**位移**上滑；面板本身不缩放、不淡入。
- 时长：黑 110 ms + 上滑 **300 ms**，从点击到可用 ≈ 400 ms。
- 缓动：逐帧位移序列 21 / 32 / 21 / 11 / 9 / 5 / 4 / 3 / 2（dp/帧）→ 前 40% 走完 60% 位移，**强 ease-out**（近似 `cubic-bezier(0.16,1,0.3,1)`），末段 60 ms 收尾，**无回弹**（灰度单调上升，无过冲）。
- 错峰：面板内容随面板整体移动，**无逐项 stagger**；代价是有一次数据替换（昵称占位→真名）。
- 缺陷：起始 110 ms 纯黑（Activity 窗口背景 / 冷启动），视觉上是「闪黑一下」。

### D. 全屏 sheet 关闭

- 类型：面板下滑 + 遮罩同步淡出（两者同帧开始）。
- 时长：**200 ms**（14.50→14.72）。
- 缓动：差分数列 5.6→6.7→15.8→16.5→18.1→25.7→15.2→26.6→13.3→20.4→24→9.8 → 中段最快、末帧急停，接近 **ease-in-out**（与打开不对称：打开 ease-out，关闭 ease-in-out 且更短）。
- 残留：关闭后左上角 × 淡影约 100 ms（跨窗口 crossfade 的副作用，不该出现）。

### E. 二级页 push（我的 → 主题）

- 类型：**右→左位移**（新页整页滑入）+ 下层 sheet 反向小位移（视差 ≈ 24 dp，即屏宽 7%）。
- 时长：**250 ms**；另有前置 100 ms 黑屏。
- 缓动：25.6 / 39.7 / 32.1 / 26.4 / 21.8 / 18.3 / …（递减）→ ease-out。
- 错峰：页面整体一起动；**顶栏图标 × → ← 在滑入过程中切换**（9.85 s 有一帧额外的强变化，即图标/SVG 替换）；卡片纹理晚于页面到位 ~200 ms。
- 缺陷：① 前置黑屏 ② 第三张色卡先显示「灰底 + 2 个彩点」的占位再变色 ③ 面板底下的 sheet 在最前 200 ms 被黑掉，只有最后 30 ms 才露出视差条。

### F. 二级页 pop

- 类型：右滑出 + **透明度淡出**（10.90 s 帧里卡片明显半透明），下层 sheet 视差回归。
- 时长：**180 ms**（比 push 短 70 ms）。
- 缓动：3.8 / 4.0 / 6.1 / 9.7 / 14.0 / 15.0 / 10.1 → 先慢后快再收，ease-in-out。
- 错峰：位移与外层淡出同时，卡片纹理不单独动。

### G. 副标题轮播（等级卡）

- 类型：容器内**上行位移 ≈ 20 dp + 交叉淡入淡出**，两行短暂同时可见（11.78 s 帧可证）。
- 时长：**170 ms**；停留 ≈ 1 s（11.00→11.78 内容不变）。
- 关键：**容器高度固定**，轮播不引起布局跳动；不打断滚动。
- 内容：「你正在限时体验 Lv 1 权益」→「所有基金 0% 认购费」→「外币兑换定存高达 21% p.a.」

### H. 骨架屏

- 首帧即骨架（tab 切换同一帧出现），**没有转圈、没有 spinner**。
- 结构：`#F4F4F6` 页面底 + 白卡内灰条（条高约 14 dp、圆角 7 dp、行距 10 dp），图标位用 40 dp 圆占位。
- 填充：数据到达后**分块替换**（50–150 ms 错峰），替换本身无跨淡；持仓页 6.53→6.90 整体 370 ms。
- 副作用：新闻页在整个录屏里都没加载完（骨架停留 >300 ms 无人抱怨，说明骨架观感可接受）。

### I. 列表滚动（我的面板）

- 一次 fling：位移 ≈ 230 dp / 0.6 s，末段 200 ms 内减速到 0，**无 overscroll 回弹**。
- 无滚动条、无「大标题收起」、无顶栏模糊；内容在固定的 × / 主题 行下方**硬裁切**（没有渐变蒙版）。

### J. 卡片进场（资产详情）

- 三张彩色资产卡 + 下方大骨架卡，随 sheet 上滑一起进入；卡内数字是骨架条，随后替换。
- 卡与卡之间**重叠堆叠**（每张下移约 12 dp、轻微投影），像一叠卡。

## 4. 今日小票可以学的（7 条，具体到文件/参数）

> 现有实现参照：`ui/AppShell.kt`（4 tab + 64 dp 胶囊 + 右侧 64 dp 圆）、`ui/components/Sheet.kt`（顶圆角 `XpRadius.l` = 18/20 dp + 36×5 抓手）、`ui/components/Grouped.kt`（行高 48/56 dp）、`ui/components/ShimmerBlock.kt`、`ui/theme/Tokens.kt`（`XpRadius` / `XpMotion.snappy` 0.35 s / `XpEase.out` 0.23,1,0.32,1）。

**1. 一级 tab 改成 0 ms 硬切，把动效预算全给浮层**
`AppShell.kt` 的 `NavHost` 显式 `enterTransition = { EnterTransition.None }`、`exitTransition = { ExitTransition.None }`（现在是显式写的 `fadeIn(tween(120))` / `fadeOut(tween(90))`）。理由：参考 App 的 6 次一级切换全是单帧硬切（1.88 / 2.90 / 3.47 / 4.15 / 4.80 / 5.70 s），而「有动画」的部分全部集中在 sheet/push。硬切还能消除「切 tab 时列表位置在变」的错觉。

**2. 选中 pill 改成「填满槽位的胶囊」**
`AppShell.kt` `TabItem`：`RoundedCornerShape(14.dp)` → `999.dp`；宽 = 槽宽 − 8 dp（64−8 = 56 dp）、高 40 dp、色 `XpColors.Fill` alpha 1.0（现在 `0.7f * pill`）；`iconScale 1.1` 保留（参考 App 也放大图标）。参考值：pill `#EAEAEA`、slot 84×38–44。

**3. 浮层圆角与行高统一成一套浮层规格**
`Sheet.kt`：全屏 sheet 的顶圆角从 `XpRadius.l`（18/20）改为新增 `XpRadius.sheet = 32.dp`，顶边距状态栏 6 dp；`Grouped.kt` 行高 48 → **52–54 dp**，带副标题 56 → **76 dp**；`Grouped.kt` 卡间距与页边距统一 12 dp（参考实测 12/12），卡圆角继续用 `XpRadius.m`（11/14，≈参考的 12）。

**4. 二级页 push 用「新页滑入 + 底层 24 dp 视差 + 180 ms pop」**

## 5. 不要学的

1. **转场闪黑 100 ms**：我的 / 主题 / 资产详情三处都有 7 帧纯黑。这是新窗口（Activity）窗口背景造成的，属于 bug 级瑕疵；我们用 Compose 单 Activity + `Modifier.blur`/浮层，天然没有这个问题，绝不能为「像原生」去复刻。
2. **同一分区两种导航条**：4.80 s 先出 4 tab（投资高亮），5.00 s 才淡变成 5 tab 专区导航；1.88 s 却是同一帧直接换。用户无法预期。我们若要二级专区，就用 push 页 + 返回，或在进入时就换 tab，不做「原位换皮肤」。
3. **动画过程中重排内容**：资产详情（16.4 s）与我的面板（7.9 s）都在动画里换了内容（列表顺序 / 昵称占位）。动画期间结构必须冻结，数据到了再替换文本。
4. **异步图片占位可见**：主题色卡先「灰底 + 2 个彩点」再变色。我们的 `XpRadius`/`XpColors` 色块一律用代码填色，不要引入需要下载的纹理图。
5. **营销密度的首页**：余额下面两排 8 个入口 + 广告位 + 「限时 3 倍」角标 + 底部整幅 banner。我们的「记账」页是账单列表，顶部汇总条 ≤88 dp 的克制设计不变。
6. **44 sp 巨号余额 + 240 dp 宽数字**：视觉权重过大，且会诱导用户把 App 当资产看——今日小票的金额主角是「今天花了多少」，用 22 sp/600 就够。
7. **磨砂半透明导航胶囊**：需要实时 backdrop blur（Android 12+ `RenderEffect` 或 `Modifier.blur` 采样），在低端机上掉帧且难以在深/浅两套主题里保持对比度。我们的「`Card` 94% + 32 dp 圆角 + 一档柔影」已经达到同样的「浮」感。
8. **无渐变原则的例外**：参考 App 的山麓绿 45° 线性渐变、橙黄投资卡渐变——我们只保留小票纸本身的暖纸色，App chrome 依然无渐变。
